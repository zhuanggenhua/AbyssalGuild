# InfoPanel mandatory-action appearance

Locked source a11a89b04cea8370476f2559b639bb9b4cbc08d8: UIRoot's InfoPanel/ActionButton contains RectTransform, CanvasRenderer, TextMeshProUGUI and TextButton only, with no child, Image or Selectable. Its declared font color is (1, 0.9, 0.3, 1), normal style and no vertex gradient. InfoPanel.Setup supplies a click action but no hover callback; TextButton changes underline on pointer enter/exit/disable, not text color. SetColor callsites in journal headers are not this action.

The native adapter is restricted to the locked provenance and three admitted action labels, plus a valid normal, non-gradient source text record resolved from that exact hierarchy. It removes native Button state backgrounds and uses the source declared text tint across normal, hover, pressed, disabled and focused states. Empty styleboxes retain the previous effective content margins, so this does not change the accepted outer hit rectangle or native glyph positioning. Focus style, font shadow, underline geometry, dispatch and input priority are unchanged. Source records are cached during HUD configuration; repeated sync does not allocate new styleboxes or reapply unchanged tint. HUD reconfiguration restores prior overrides before rebinding the source record and recapturing effective margins from the replacement theme on the next sync. Unknown labels, missing provenance or unsupported/replacement records restore exact prior local overrides or inherited theme behavior.

This closes unwanted native decoration/state tint only. The declared color is not a claim of exact TMP Color32 quantization, SDF coverage or framebuffer parity. The existing native centered glyph origin, underline raster and mixed InfoText renderer remain separate unaccepted contracts. A source alpha/coverage diagnostic failure must not be waived by this change.

Regression tests cover exact effective margin/minimum preservation, focus style identity, repeated calls, restoration under replacement theme/source records, unsupported font state, and actual Board Feed People / Start Day / Return to Title lifecycle, resizing, admitted dispatch and hit bounds. An unchanged prior Board is the negative control.
