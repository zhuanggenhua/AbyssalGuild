# Locked InfoPanel action outer layout

Scope: English Feed People, Start Day, Return to Title from locked DayCycleManager, original UIRoot ActionButton. This adapts only the last active child's outer layout/hit rectangle and height reservation. It does not claim native glyph layout, underline, tint, or complete InfoText parity.

Original: VerticalLayoutGroup, upper-left alignment, zero spacing/padding, both dimensions controlled, neither force-expanded; children InfoText then ActionButton. Vertical ContentSizeFitter preferred mode sums active child heights. Thus the action's bottom and left are independent of preceding text height. TMP action size30, static primary font, margins20 each, top/left alignment, single-line labels. Scalar preferred-size formulas yield height73.5199966430664 and widths210.58999633789062 /164.5399932861328 /227.07000732421875 respectively. These include margins and original preferred rounding. No vendor glyph tables or binaries are shipped here.

The source action's full padded RectTransform is raycast-target enabled with zero raycast padding. The adapter retains the existing real Button callbacks, modal guards, request priority and visibility. Unknown labels or absent/mismatched source provenance retain legacy40-height reservation and legacy geometry. Hidden actions reserve zero. Restoring source provenance with unchanged text still updates geometry.

Native baseline reserved40, positioned at bottom−40 with x+20 and width360. Its visible Button theme minimum actually made height43. This adapter sets supported outer dimensions explicitly and reserves the same source height. Native centered text/glyph baselines/underline and underlying InfoText height/clipping remain known residuals, not fixed by arbitrary offsets. Source labels are English literals; no translated source callsite was established, so translated labels do not inherit these metrics.

Tests cover data-only admission and reservation, actual headless Board end-day/feed/new-day/game-over visibility, callback consumption, fixed bottom/left and inside/outside rectangle points, resize mapping, missing-provenance and unknown-label reset. Geometry bounds tests are not native-pointer routing or framebuffer parity. No Unity renderer was executed. The separate private original provider-formula calculation and unchanged-baseline negative control are engineering evidence, not source screenshot acceptance.
