# 战斗卡牌持有位置与释放取样

来源锁定 CardLoop `a11a89b04cea8370476f2559b639bb9b4cbc08d8` 的 CardController、CardStack、Board 和 CombatRect。此增量不引入新玩法。

## 已接入的范围

只接入来源匹配、未变换 Board 中的玩家进攻方、非最后一名进攻者，且不是当前攻击或受击对象。任务须无进行中的攻击，或为 Arrow/Magic 的 travel/return，卡牌没有其它已知移动、装备或周期表现 owner。普通拖动、其它战斗分支保留原入口。

Combat PointerDown 捕获实际显示位置与地面鼠标位置的偏移，不立即调用拖动更新。鼠标移动事件只记录坐标，Board 的实际运行帧读取该坐标并更新实际卡牌位置：原 DragHeight 与 ClampToBounds，不提前执行顶栏放置限制。CombatRect 的槽位不冒充正在被拿起的卡牌位置。

PointerUp 在布局刷新之前取最后实际卡牌位置；未处理的移动事件和释放事件自身的坐标不等于另一帧 Update。原来源的“留在矩形内”与“逃离矩形”的选择使用该位置。成功的无接触释放，Flee 内部布局回调在离队卡堆注册前看到原持有 XZ，注册后才施加最终放置规则。仅当预览剩余战斗矩形和所有普通卡堆没有需要分离的接触时，才启用该释放事务；复杂分离沿用原适配路径，不视为验收通过。

保持原进行中的远程攻击 execution、弹道年龄/端点及 RNG。新增测试通过真实 Board 的指针适配入口、输入事件和运行帧驱动，覆盖抓取偏移、越界、拖入顶栏、新事件未更新即释放、Flee 回调先于注册和延迟放置限制。

## 未验收

最终释放后的普通卡牌显示高度映射、从持有位置到落地位置的 DOTween 对等动画仍未在此项解决。原引擎对完整 CardController 点击阈值历史、触控、近战目标、终局 Flee、复杂重叠分离的全流程尚未通过此切片；不要把此测试当作这些流程、GPU 截图或整体迁移验收。未上传原始素材或参考截图。
