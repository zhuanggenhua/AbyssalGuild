# 来源基准

## 选择依据

迁移对象是基础 StackCraft，而非 CardLoop 当前 main 的新剧本。已静态读取原仓库历史：

1. `f6967871` 是更早的 Unity 工程基线，不含 `Assets/StackCraft`。
2. `a11a89b04cea8370476f2559b639bb9b4cbc08d8` 首次包含完整 `Assets/StackCraft`，本次锁定此版本。
3. `62b5cfb7` 仍含模板，但较首次版本改过五个材质和 GameDirector、SaveSystem 等文件。
4. `334fc57c` 删除了模板目录，后续 `a275016a` 加入《寒夜营地》。这些不是本次迁移基准。

来源通过 `git archive` 导出，没有切换或改动来源仓库；目标仓库初始为空、默认分支为 main。模板的内置文档写明产品名、作者及 Unity 2022.3.62f2，但未查到明确产品发行版本号。因此不将历史口头的“1.0.0”作为文件中已验证的事实。

## 验证口径

`source-lock.json` 记录相对于模板根目录的全部文件路径、长度与 SHA-256、来源提交和 Git tree。`check_source_lock.py` 验证完整副本，而非只验证一份报告存在。缺失、修改、多余文件都会失败；它不启动 Unity，也不会修改源文件。

原模板已包含项目此前适配的新输入系统脚本，故“首次仓库模板”不等于声称拿到了作者发行压缩包的逐字原件。后续每项行为均注明实际依据，不从新版 CardLoop 反推。

## 许可边界

作者文档的第三方声明把 DOTween 标为 MIT、SVG Repo 衍生图与 King's Feast 音乐标为 CC0。这不是模板自身源码、模型、全部图片或整包可公开再分发的许可证。源仓库公开也不自动授予重新分发权。

本仓库先保存迁移工具、来源元数据、独立重写的规则实现和测试，不包含第三方原文件。完整内容的本地导入结果保留在忽略目录，待明确可分发范围后再决定公开内容。不得给未核验的第三方内容补造许可证。
