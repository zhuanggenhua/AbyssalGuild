# Optional private exact alpha cache

This is an optional build-time optimization, not new source rendering behavior. Use the verified official Godot 4.7.2 editor and templates:

```
GODOT=/absolute/path/Godot_v4.7.2-stable_linux.x86_64 python tools/export_linux.py --templates /private/Godot_v4.7.2-stable_export_templates.tpz --output /private/new-release --alpha-cache
```

Without `--alpha-cache`, the existing export workflow remains unchanged. The exporter does not copy any cache from the checkout. With it, the verified temporary licensed project is imported normally, then `build_alpha_cache.gd` applies the existing strict grayscale validator and alpha=R conversion exactly once. The private data is generated after import and checked again in the final PCK. No licensed files, cache index or payload belong in public Git. Source-free projects still work without the cache.

## Data and failure contract

The verified temporary export stores the generated index SHA256 in a trusted project setting. Runtime checks it before JSON parsing. Missing setting or any index change means the old conversion path. This is not a signature and cannot defend against replacement of the entire PCK together with its project settings.

The optional JSON index has a fixed location and 1 MiB cap; at most512 entries. Payload names are only lower-case32-hex GUID plus `.bin`, rooted in the fixed private directory. No index-selected ResourceLoader, script, object/Variant deserialization or arbitrary paths. Payloads contain only DEFLATE-compressed RGBA8 image bytes, with exact mip chain size and SHA256. Bounds are2048 per dimension and32 MiB compressed/decoded; larger future source images use the old path rather than modifying pixels.

Bindings include the official engine string and exact `ed1daf0bf001b61586d9930840f2f1394092c079` hash (generation and runtime), conversion schema, original source manifest hash and importer fields, current imported `.ctex` hash, compressed payload hash and decoded bytes hash. Engine/source/importer/import-cache mismatch, missing payload, invalid JSON/schema/type/path/dimension/size/hash all reject the cache and retain current conversion. A malformed compressed stream with a matching forged hash is still bounded and has no execution path; the engine may log a decompression error before falling back. The index is a local generated-data integrity binding, not a signature against an attacker who can rewrite all authorized project files.

The original decoded RGB is retained. Non-grayscale source images are not admitted. Mipmaps are generated by the existing source adapter, not by a new approximation. The generator tests exact bytes/mips before admitting each entry; export verifies all admitted source images against the original algorithm and exercises stale/corrupt binding fallback. This is not a claim of Unity GPU pixel parity.

## Cost and evidence scope

Earlier isolated 479-card Day64 profiling found27 grayscale conversions consuming about3.9 seconds, while pure save staging was tens of milliseconds. A private compressed Image-resource proof was about13 MiB and reduced first-use headless Continue from roughly6.1 to1.9–2.4 seconds. That prototype is **not** this data-only format; actual final-package measurements must be reported separately. Warm runs, OS page cache, native main-thread stalls and GPU upload are different measurements. The optional cache trades private package space for avoiding the first-use GDScript pixel loop. No native no-stall guarantee follows from these timings.
