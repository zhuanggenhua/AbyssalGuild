# 装备面板的外部按下

实际 Main/Island 使用原 `StackCraftInput.cs` 8–29、41–51 和
`EquipmentPanel.cs` 124–133、157–178 的独立检查：GUI 即使消费了按下，
携带面板的游戏场景仍按本帧最后的共享指针位置投射实体射线。命中本面板保留
它，命中任一装备保留全部面板，其余关闭。主触点和物理左键才产生检查；
第二触点、触摸模拟鼠标和松手不重复触发。保留原面板点击开合和卡牌拖动入口。

集成检查在锁定原目录的真实面板、装备、投影相机和 HUD 上注入鼠标、触摸，
覆盖原位与同帧移动、HUD 消费、第二触点以及主触点外部按下。此检查不是物理
触屏或 Unity 截图比对；不同组件之间的同帧执行顺序也没有声称完全一致。
